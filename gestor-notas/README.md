# gestor-notas

Proyecto 1 de mi portafolio. Sistema simple en TypeScript para guardar alumnos y calcular promedios.

## Qué hace
- Define alumnos con nombre y notas
- Calcula promedio con función propia
- Recorre la lista con `for` y muestra resultados

## Cómo correrlo
```bash
npm install
npx tsx src/index.ts
```

## Qué aprendí
- `type` como molde, `function` como maquinita, `array` + `push` + `length`, `for` como dedo que recorre
